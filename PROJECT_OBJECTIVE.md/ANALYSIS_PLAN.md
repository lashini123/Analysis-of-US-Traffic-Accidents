## Analytical Questions and Planned Visualizations

| Question                                                   | Visualization Type                 | Purpose                      |
| ---------------------------------------------------------- | ---------------------------------- | ---------------------------- |
| How have traffic crashes changed over time?                | Line chart (crashes per year)      | Identify long-term trends    |
| Are there seasonal patterns?                               | Line chart (crashes per month)     | Detect seasonal risk periods |
| Which weather conditions are most associated with crashes? | Bar chart (top weather conditions) | Environmental impact         |
| Which lighting conditions lead to more crashes?            | Bar chart                          | Visibility influence         |
| How does speed limit affect injury counts?                 | Scatter plot                       | Severity relationship        |
| What is the distribution of total injuries?                | Histogram                          | Injury severity pattern      |
| Are there extreme injury outliers?                         | Box plot                           | Identify abnormal events     |
| Which crash types are most frequent?                       | Bar chart                          | Structural crash patterns    |
