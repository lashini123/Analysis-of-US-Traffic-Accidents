# End-to-End Analysis of US Traffic Accidents

## Project Overview
This project performs an end-to-end analysis of traffic crash data using Python, following a professional data analytics workflow from raw data ingestion to insight generation.

Due to file-size constraints, the original raw dataset is not included in this repository. A representative cleaned sample dataset is provided for analysis.

---


## Workflow

1. Load raw crash data (local only).
2. Create a representative 200,000-row sample.
3. Clean data and engineer time features.
4. Perform exploratory data analysis (EDA).
5. Generate insights through visualizations.

---

## Key Insights

- Crash occurrences show clear yearly trends.
- Clear weather and daylight conditions dominate crash events.
- Speed limit has a positive relationship with total injury count.
- Fatal crashes represent a small percentage of total crashes, but remain a major safety concern.
